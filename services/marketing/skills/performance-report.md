# Channel performance report

1. `channels` for the brand, then `analytics` for each channel.
2. Write a script and run it to compute per channel: engagement rate, click-through rate, and change against the prior
   period. Print every figure. Do not state a number the script did not print — the check will block the reply.
3. Rank channels by the metric that matters for the goal, not by follower count. Follower count is not a result.
4. Separate the two questions the reader actually has: what happened, and what to do next. Answer the first in one
   sentence and the second in no more than three specific changes.

Call out anything that looks like a measurement artefact rather than a real move — a spike concentrated in one post, a
click count with no matching impressions, a channel with too few posts to read anything from. A report that presents
noise as a trend is worse than no report.
